# Noise Floor documentation

Noise Floor is a guitar, piano and singing trainer that runs in the browser and listens to your real instrument or voice through the microphone. These pages say what it does, how it measures, and how it is built.

*Die App selbst ist zweisprachig (Deutsch und Englisch); diese Dokumentation ist auf Englisch. Eine deutsche Übersicht steht in der [README.de.md](../README.de.md).*
